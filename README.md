# bg2-emc-bridge
A NeoForge 1.21.1 mod that lets Building Gadgets 2 pull blocks from your ProjectE EMC network automatically, so you never have to restock your inventory.

## Requirements
- NeoForge 1.21.1
- Building Gadgets 2
- ProjectE

## Tested with
- NeoForge 21.1.229
- Building Gadgets 2 1.3.9
- ProjectE PE1.1.0
- Project Expansion 1.21.1-1.0.6

## Installation
Drop the jar into your mods/ folder alongside Building Gadgets 2 and ProjectE.
